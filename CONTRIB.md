# Contributing to TaskMate

TaskMate is first and foremost a learning, experimental and incremental operating-system project.

The goal is not to build everything at once, nor to reproduce an existing RTOS, but to understand how the pieces fit together 
and improve them step by step. Architecture, portability, simplicity and readable code matter as much as features.

Contributions are welcome from anyone interested in operating systems, embedded programming, low-level C, hardware, or simply curious about how such a system grows.

There are many ways to participate:

* review documentation or source code.
* discuss architecture and design choices.
* inspect critical system code.
* write or improve drivers.
* test on real hardware.
* port TaskMate to another architecture.
* improve tools, build scripts or tests.
* report bugs, strange behaviours or questionable design decisions.

Small contributions are just as useful as large ones. A documentation correction, an observation during a code review, 
or a driver tested on a different board can all move the project forward.

TaskMate evolves incrementally. Changes should therefore try to remain understandable, focused and consistent 
with the existing architecture. Experiments are welcome too: this is part of what the project is for.

If low-level software, old-school computer engineering and learning by building things sound interesting, you are welcome to take part.

Before contributing, please have a look at the project documentation for coding conventions, architecture rules and development workflow.
