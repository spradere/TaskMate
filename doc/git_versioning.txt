1. Create branch :

git switch main_new
(git pull)
git switch -c feat/preempt-protected-i2c
git push -u origin HEAD:refs/heads/feat/preempt-protected-i2c

2. Work, commit :

git add .
git commit -m "Implement stuff"
git push

or make push M="Implement stuff"

3. Work done -> test ok -> merge :

git switch main_new
git merge --no-ff test_branch
git push origin main_new

4. Delete branch :

git branch -d test_branch
git push origin --delete test_branch

5. close a version

update file version.h
git commit -am "Bump version to 0.7"
git tag -a v0.7 -m "TaskMate 0.7 - HAL + no_global stable"
git push origin --tags
