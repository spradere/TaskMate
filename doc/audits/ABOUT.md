# About audits

Audits are snapshots of the system at a specific point in time. They are working records, not living
documentation intended to evolve alongside the code.

Each audit focuses on a specific topic. It records identified problems and provides an organised,
step-by-step resolution strategy so that findings can be tracked and addressed methodically.

When a problem is resolved, its text must be struck through with `~~`. Once every finding in an
audit has been addressed, the audit must be deleted.

| Priority | Meaning |
| --- | --- |
| `P0` | Critical or blocking issue; address immediately. |
| `P1` | Important issue; address as a high priority. |
| `P2` | Non-blocking improvement; address after higher priorities. |
